The inputs and outputs of the module that Approvals uses.

Inputs

Name Default Description
repository The repository whose workflow plans and applies.
environments One environment per workspace, named after it.
auto_apply [] Environments that apply without an approval, like HCP Terraform's auto apply. List the same workspaces in the action's auto-apply input.
reviewer_teams [] IDs of the teams whose approval starts an apply.
reviewer_users [] IDs of the users whose approval starts an apply.
prevent_self_review false Whether the person who pushed the change may approve its apply. Leave it off when one person does both.
can_admins_bypass false Whether repository administrators may start an apply without an approval.

At least one reviewer team or user is required, unless every environment is in auto_apply.

Outputs

Name Description
environments The environments, by workspace.
